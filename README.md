# 🚀 OS-Lab: SJF & SRTF Simulator

![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=for-the-badge&logo=html5&logoColor=white)
![React](https://img.shields.io/badge/React-20232A?style=for-the-badge&logo=react&logoColor=61DAFB)
![Tailwind CSS](https://img.shields.io/badge/Tailwind_CSS-38B2AC?style=for-the-badge&logo=tailwind-css&logoColor=white)

**OS-Lab** adalah sebuah aplikasi web interaktif (Single Page Application) yang dibangun sebagai media pembelajaran untuk mata kuliah **Sistem Operasi (SO)**. 

Aplikasi ini berfokus pada simulasi algoritma penjadwalan CPU:
1. **SJF (Shortest Job First)** - *Non-Preemptive*
2. **SRTF (Shortest Remaining Time First)** - *Preemptive*

Berbeda dengan media pembelajaran biasa yang kaku, website ini menawarkan visualisasi *Gantt Chart* secara otomatis, perhitungan instan, serta UI/UX modern dengan palet warna elegan.

---

## ✨ Fitur Utama

- 📖 **Materi Terstruktur:** Penjelasan teori SJF & SRTF yang ringkas, visual, dan dilengkapi rumus perhitungan *Turnaround Time* (TAT) serta *Waiting Time* (WT).
- 🧮 **Simulator Interaktif:** 
  - Input *Arrival Time* (AT) dan *Burst Time* (BT) dinamis.
  - Tombol **Acak Data** untuk pengujian cepat.
  - Pilihan mode **SJF** atau **SRTF**.
  - Visualisasi **Gantt Chart** yang digambar secara presisi menggunakan proporsi waktu.
  - Tabel hasil perhitungan metrik dan rata-rata (Average TAT & WT).
- 🎲 **Kuis Dinamis (Randomized):** Menguji pemahaman pengguna dengan **10 soal yang diacak** otomatis dari total **50 Bank Soal** setiap kali kuis dimainkan.
- 🎨 **Desain Elegan:** Menggunakan palet warna *Plum/Mauve/Pink* khusus yang memanjakan mata, dibuat dengan Tailwind CSS.

---

## 🛠️ Teknologi yang Digunakan

Proyek ini dirancang agar sangat portabel dan mudah didemokan. Tanpa memerlukan *backend* atau proses instalasi *Node.js* (*zero-build-process*).

- **Core:** HTML5, CSS3, JavaScript (ES6+)
- **Library UI:** React JS (via CDN)
- **Styling:** Tailwind CSS (via CDN) dengan Custom Config
- **Compiler:** Babel (Standalone) untuk parsing JSX langsung di browser
- **Icons:** FontAwesome 6

---

## 🚀 Cara Menjalankan Aplikasi

Sangat mudah! Anda **tidak perlu** menginstal server, NPM, atau *environment* apa pun.

1. Unduh atau *clone* repositori ini.
2. Buka folder proyek di komputer Anda.
3. Cari file `index.html`.
4. **Klik ganda (double-click)** pada file `index.html` tersebut.
5. Website akan langsung terbuka dan siap digunakan di Browser favorit Anda (Chrome, Edge, Firefox, Safari).

> **Tip Presentasi:** Anda dapat menghosting file `index.html` ini secara gratis menggunakan **GitHub Pages**, **Vercel**, atau **Netlify** agar dosen dapat mengaksesnya melalui link internet!
